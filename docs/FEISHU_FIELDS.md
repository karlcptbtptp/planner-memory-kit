# 飞书多维表格字段模板

| 字段 | 推荐类型 | 说明 |
|---|---|---|
| 标题 | 文本 | 短标题，方便搜索 |
| 摘要 | 多行文本 | 给 AI 召回用的核心内容 |
| 正文/文档链接 | 文本/URL | 飞书文档链接、本地 runbook 路径或长正文 |
| 知识类型 | 单选 | 原则 / 项目知识 / 个人知识 |
| 可见范围 | 单选 | 全策划 / 指定项目 / 仅本人 |
| 适用项目 | 文本/多选 | `giftWeb`、`hwby`、`zgc` 等项目代号 |
| 标签 | 文本/多选 | 逗号分隔即可 |
| 状态 | 单选 | 草稿 / 待审核 / 已批准 / 废弃 |
| 敏感级别 | 单选 | 普通内部 / 项目敏感 / 禁止同步 |
| 提交人 | 人员/文本 | 上传项目知识的策划 |
| 提交时间 | 日期/文本 | 投稿时间 |
| 项目知识维护人 | 人员/文本 | 审核并对质量负责的人 |
| 审核时间 | 日期/文本 | 审核通过或驳回时间 |
| 审核意见 | 多行文本 | 说明通过、驳回或禁止同步的理由 |
| 负责人 | 人员/文本 | 知识负责人 |
| 来源 | 文本/URL | 来源任务、报告或文档 |
| 最后更新 | 日期/文本 | 维护时间 |
| 是否同步给 AI | 复选框/文本 | 勾选或填写 `是` 后才允许进入本地缓存 |

项目隔离靠 `适用项目` 和同步命令里的 `--project` 实现：`适用项目=hwby` 的知识，只会进入 `--project hwby` 的本地缓存，不会进入 `--project giftWeb`。
